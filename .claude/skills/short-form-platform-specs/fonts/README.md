# Bundled brand fonts

- `InstrumentSerif-Italic.ttf`: Instrument Serif Italic by Rodrigo Fuenzalida & Jordan Egstad, SIL Open Font License 1.1 (free for commercial use). Downloaded from Google Fonts. Used for the signature accent word in captions.

Render with libass via `ass=captions.ass:fontsdir=<this folder>`, or install the font with `cp *.ttf ~/.fonts/ && fc-cache -f`.
- `Caveat-Bold.ttf`: Caveat by Impallari Type, SIL Open Font License 1.1. Handwriting fallback for Explainer Board notes when the user hasn't supplied her own drawings.
