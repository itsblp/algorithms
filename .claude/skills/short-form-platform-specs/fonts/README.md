# Bundled brand fonts

- `InstrumentSerif-Italic.ttf`: Instrument Serif Italic by Rodrigo Fuenzalida & Jordan Egstad, SIL Open Font License 1.1 (free for commercial use). Downloaded from Google Fonts. Used for the signature accent word in captions.

Render with libass via `ass=captions.ass:fontsdir=<this folder>`, or install the font with `cp *.ttf ~/.fonts/ && fc-cache -f`.
- `Caveat-Bold.ttf`: Caveat by Impallari Type, SIL Open Font License 1.1. Handwriting fallback for Explainer Board notes when the user hasn't supplied her own drawings.
- `PlayfairDisplay-Italic.ttf`: Playfair Display Italic by Claus Eggers Sørensen, SIL Open Font License 1.1. The talking-head hook title serif (matches the user's "editing made easy" reference).
- `InterTight-SemiBold.ttf`: Inter Tight SemiBold by Rasmus Andersson, SIL Open Font License 1.1. Talking-head captions and the title's sans line (chosen by the user 2026-11-11).
- `CormorantGaramond-MediumItalic.ttf`: Cormorant Garamond Medium Italic by Christian Thalmann, SIL Open Font License 1.1. The talking-head hook title serif (chosen by the user 2026-11-11, replacing Playfair Display).
- Carousel cover fonts (2026-11-11), all from Google Fonts under the SIL Open Font License 1.1, picked as the closest free matches to the user's cover references:
  - `Montserrat-Variable.ttf` (Julieta Ulanovsky): the bold geometric sans ("Turn ... CAROUSEL" reference). Use wght 600.
  - `PlayfairDisplay-Variable.ttf` / `PlayfairDisplay-Italic-Variable.ttf` (Claus Eggers Sørensen): the high-contrast serif and italic ("Claude / weapon", "My / Recs").
  - `InstrumentSerif-Regular.ttf` (Rodrigo Fuenzalida, Jordan Egstad): the condensed editorial serif ("of carousel is winning", "the formula behind pretty photo dumps").
  - `Sacramento-Regular.ttf` (Astigmatic): the small monoline script sign-off ("design matters").
  - `ImperialScript-Regular.ttf` (Robert Leuschke): the swash script ("font").
- `Jua-Regular.ttf` (Woowahan Brothers), Google Fonts, SIL Open Font License 1.1: chunky rounded Korean hand-lettering for small Hangul accents like 새로 (matches the 서울 in the "things to do in: seoul" reference).
